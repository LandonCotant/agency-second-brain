# Runbooks

Operational procedures for deploying and operating Agency Second Brain.

This portfolio copy is curated: live credentials, Workspace admin click-paths,
and production incident timelines were removed. Remaining runbooks use
placeholder project IDs (`agency-brain-demo`), emails (`owner@example.com`),
and folder IDs (`FOLDER_ID_*_REDACTED`).

Treat these as architecture documentation, not a turnkey deploy guide for a
live Google Cloud org.
